# TBN Development — сайт (прототип)

Статический сайт на Bootstrap 5.3 для tbn.ge. Сейчас на tbn.ge стоит шаблон 2015 года (GoTo CMS) с пустыми разделами. Сборка не нужна: файлы можно открыть в браузере или выложить на любой хостинг.

Структура и движок те же, что у сайта Vinci Development; поменяны бренд, цвета и контент.

## Структура
```
index.html            главная
projects.html         каталог объектов (фильтр: все / в продаже / реализованные)
project.html?id=...   карточка объекта (varketili, akhmeteli), данные из data.js
news.html             новости и статьи
article.html?id=...   материал (шаблон)
about.html, services.html, buyers.html, contacts.html, careers.html, privacy.html, 404.html
assets/css/style.css  тема: цвета в :root (--vx-navy синий, --vx-accent оранжевый из логотипа)
assets/js/data.js     контент: компания, проекты, новости (ru/en/ka) + SVG-иллюстрации
assets/js/i18n.js     переводы интерфейса и страниц (en, ka)
assets/js/main.js     шапка, подвал, логотип, карточки, фильтр, форма
assets/img/favicon.svg
_build/make-pages.ps1 генератор внутренних страниц из общего шаблона
_build/serve.ps1      локальный сервер: powershell -File _build\serve.ps1, затем http://localhost:5173
```

## Языки: ქართული / English / Русский
- Русский текст лежит прямо в HTML. Английский и грузинский хранятся в `assets/js/i18n.js` и подставляются по атрибутам `data-i18n`.
- Язык: `?lang=ka|en|ru`, затем сохранённый выбор, затем язык браузера, иначе русский.
- Грузинский перевод сделан без носителя языка: перед запуском его стоит вычитать.

## Видео на первом экране
`assets/video/hero.mp4` (18 с, 1280×720, без звука, 4,5 МБ) и `hero-poster.jpg` — фрагмент 1:22–1:40 аэросъёмки Тбилиси с tbn.ge (`/images/video.mp4`, оригинал 6,6 мин, 514 МБ). Видео ставится на паузу кнопкой в углу и не запускается при системной настройке «уменьшить движение». Для локального просмотра нужен сервер с Range-запросами (`_build/serve.ps1` их поддерживает), иначе видео не зацикливается.
